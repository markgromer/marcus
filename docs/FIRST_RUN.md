# First-run acceptance test

A public build is ready when a new user can:

1. Clone the repository.
2. Install dependencies.
3. Bootstrap MARCUS.
4. Open the browser without manually moving secrets around.
5. Understand what MARCUS does from the dashboard.
6. Detect installed coding agents and local capabilities.
7. Select an allowed project root.
8. Discover/import existing projects.
9. Configure one reasoning provider.
10. Complete one guided approval-gated operation.
11. Diagnose a broken install with `npm run doctor`.
12. Understand what is implemented versus roadmap.

The target is a useful first experience without requiring knowledge of OS1, the original operator, or MARCUS internals.
