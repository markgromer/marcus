# Setup UX

The setup script establishes the secure local runtime. Operator identity, provider choices, project roots, coding-agent preferences and approval policy belong in browser onboarding.

The browser flow should be:
1. Welcome / explain MARCUS in one sentence.
2. Detect environment and installed agents.
3. Configure operator identity and working style.
4. Configure reasoning provider.
5. Select preferred coding agent from detected tools.
6. Select approved project roots.
7. Scan and import projects.
8. Review execution policy.
9. Land on the control center with a guided first task.

Do not require users to copy an admin token into the browser during the normal localhost path.
