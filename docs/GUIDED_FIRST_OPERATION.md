# Guided first operation

The first successful session should walk the operator through one safe, understandable task:

1. Select an imported project.
2. Ask MARCUS to inspect the project and summarize what needs attention.
3. MARCUS proposes a bounded operation.
4. The operator reviews and approves it.
5. A configured coding agent executes only inside the approved workspace.
6. MARCUS captures the result and verification evidence.
7. The dashboard shows the completed outcome.

The purpose is to create the first clear "MARCUS manages the work" moment, not merely prove chat works.
