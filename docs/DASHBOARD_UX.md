# Dashboard UX

The MARCUS home screen should communicate operational state before conversation.

Primary sections:
- **Needs You** — approvals, failures and decisions.
- **Active** — agent work currently running or recently prepared.
- **Projects** — active, stale and blocked project health.
- **Recent** — completed operations and meaningful changes.
- **Chat** — persistent operator conversation with MARCUS.

The dashboard should make the distinction from a generic chat application obvious within seconds.
