# Status

## 0.1.0 baseline

The repository now contains the portable MARCUS kernel: first-run operator configuration, modular prompts, local authenticated API/UI, durable project and memory state, exact-action approvals, allowed-workspace enforcement, OpenAI/Anthropic chat providers, and Claude Code/Codex coding-agent adapters.

The next extraction phase is parity work: bring over the mature desktop bridge, browser operator, semantic/vector memory, richer project evidence, messaging/calendar/email integrations, deployment providers, and mobile/voice experiences without reintroducing operator-specific state.

The repository should remain public-safe at every commit. `npm run check` is the gate for known extraction markers, likely credentials and accidentally tracked runtime data.
